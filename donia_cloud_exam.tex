\begin{enumerate}
\item اشرح الفرق بين الـ Block والـ Element في منهجية BEM، ومتى يجب استخدام Modifier. قدّم مثالاً عملياً يُظهر HTML و CSS.
\item لنافذة منبثقة (modal) بالـ Block اسم \texttt{modal}، اكتب أسماء Classes المناسبة باستخدام BEM للعناصر: المحتوى (content)، العنوان (header)، الإغلاق (close)، و Modifier يُحدد حالة الظهور (is-open).
\item وضّح كيفية استخدام CSS Custom Properties (متغيرات CSS) مع BEM لتنفيذ Theming (السمة). قدّم مثالاً يُظهر كيف يمكن ل Modifier تغيير لون الخلفية والخط.
\item ناقش التحديات التي تواجهها عند دمج BEM مع أُطر العمل الحديثة مثل React أو Vue. كيف يمكن تكييف BEM مع JSX أو قوالب Vue مع الحفاظ على قابلية الصيانة؟
\item كيف تتعامل مع اتجاه الكتابة (RTL) عند تسمية الـ Classes باستخدام BEM؟ قدّم استراتيجية مُقترحة لتعديل أسماء العناصر والـ Modifiers لدعم اللغات من اليمين لليسار.
\item قدّم مثالاً على "Block Mix" في BEM، حيث يتم تضمين Block داخل آخر مع الحفاظ على استقلالية Namespace. وضّح كيفية كتابة HTML و CSS لكلا القطاعين.
\item ما الفرق بين Boolean Modifier و Key‑Value Modifier؟ متى تُفضّل كل نوع؟ قدّم حالة استخدام لكل منهما.
\item اكتب دالة JavaScript (أو TypeScript) تُنشئ اسم class مع BEM من ثلاثة أجزاء (Block, Element, Modifier). وضّح المدخلات والمخرجات.
\item في سياق Design System، اشرح الخطوات اللازمة لبناء مكتبة مكونات (Component Library) مبنية على BEM، من التسمية إلى التوثيق.
\item قدّم سيناريو يتطلب استخدام Modifier مع قيمة (value) لتغيير السمة (theme) لمكون، وضح كيف يمكن تطبيقه باستخدام CSS Variables و BEM.
\item ناقش تأثير استخدام عدد كبير من Classes (BEM) على أداء المتصفح، واقترح أفضل الممارسات لتحسين الأداء.
\item اشرح كيفية استخدام BEM مع CSS‑in‑JS (مثل styled‑components). هل تظل المبادئ ذاتها؟ قدّم مثالاً عملياً يُظهر كتابة مُكوَّن React باستخدام BEM.
